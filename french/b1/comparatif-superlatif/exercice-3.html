Le comparatif et le superlatif — Niveau 3 : Maîtrise
Récapitulatif : les règles et les exceptions
LE COMPARATIF
La comparaison porte sur…+ Supériorité= Égalité− Infériorité
un adjectifplus + adjectif + queaussi + adjectif + quemoins + adjectif + que
un adverbeplus + adverbe + queaussi + adverbe + quemoins + adverbe + que
un nomplus de + nom + queautant de + nom + quemoins de + nom + que
un verbeverbe + plus queverbe + autant queverbe + moins que
Formes particulières
Mot de départ+ Supériorité= Égalité− Infériorité
bon adj.meilleur(e)(s) + queaussi bon(ne)(s) + quemoins bon(ne)(s) + que
mauvais adj.pire(s) ou plus mauvais(e)(s) + queaussi mauvais(e)(s) + quemoins mauvais(e)(s) + que
bien adv.mieux + queaussi bien + quemoins bien + que
À retenir :
  • L'adjectif s'accorde avec le nom ou le pronom qu'il qualifie ; l'adverbe reste invariable.
  • Pire a la même forme au masculin et au féminin ; au pluriel il devient pires. Le choix entre pire et plus mauvais dépend du contexte.
  • De devient d' devant une voyelle ou un h muet : plus d'amis.
  • Que devient qu' devant une voyelle ou un h muet : plus grand qu'elle.
LE SUPERLATIF
Le superlatif porte sur…Le plus haut degréLe plus bas degré
un adjectifle / la / les plus + adjectifle / la / les moins + adjectif
un adverbele plus + adverbele moins + adverbe
un nomle plus de + nomle moins de + nom
un verbeverbe + le plusverbe + le moins
Formes particulières
Mot de départLe plus haut degréLe plus bas degré
bon adj.le meilleur / la meilleure / les meilleur(e)sle / la / les moins bon(ne)(s)
mauvais adj.le / la / les pire(s) ou le / la / les plus mauvais(e)(s)le / la / les moins mauvais(e)(s)
bien adv.le mieuxle moins bien
À retenir :
  • Avec un adjectif, le / la / les et l'adjectif s'accordent : les voitures les plus rapides.
  • Avec un adverbe, le reste invariable : ce sont elles qui courent le plus vite.
  • Devant une quantité exprimée par un nom, on garde le plus de / le moins de : elle a le plus de livres.
  • Le degré le plus élevé n'est pas forcément positif : le pire exprime le degré le plus élevé de mauvaise qualité.
